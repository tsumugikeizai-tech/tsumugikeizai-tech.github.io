つむぎ指標 プライバシーポリシー

制定日：2026年11月7日

取得する情報

Googleアカウントでの許可にもとづき、YouTube Data API と YouTube Analytics API から、許可したチャンネル自身の動画の情報（タイトル・公開日時など）と集計値（視聴回数・平均視聴率・流入元など）を読み取ります。権限は youtube.readonly と yt-analytics.readonly の2つだけです。

使い道

運営者が自分のチャンネルの成績を振り返るために、運営者のコンピューターに記録します。広告・販売・第三者への提供には使いません。

保存と共有

読み取った数字と許可のトークンは、運営者のコンピューターにだけ保存します。第三者へは渡しません。集計の結果は、運営者だけが見る通知（Discord）に送ることがあります。

許可の取り消し

Googleアカウントの「サードパーティのアクセス」（https://myaccount.google.com/permissions）から、いつでも取り消せます。

本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。また YouTube API サービスを利用しています（YouTube 利用規約、Google プライバシーポリシー）。
